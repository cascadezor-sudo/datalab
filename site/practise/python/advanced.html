    Создай несколько экземпляров обоих классов и посмотри, что будет выводиться.

    Смысл задания — сравнить лёгкую стандартную модель данных (dataclass) и модель с валидацией от Pydantic. Заполни одинаковые поля в обоих классах, создай несколько пользователей и выведи объекты, чтобы увидеть различия в представлении и проверке типов.   2. Асинхронные запросы

    Научиться писать асинхронный код с async/await и параллельно запускать задачи.

    Создай асинхронную функцию fetch_data(url), которая имитирует загрузку данных с сервера. Функция должна использовать asyncio.sleep(1) для имитации задержки и возвращать строку "Data from {url}". Затем создай функцию main(), которая параллельно загружает данные с трёх разных URL и выводит результаты.

    Главная идея — не просто написать async def, а запустить несколько ожиданий одновременно через asyncio.gather(...) или созданные задачи. Если сделать всё правильно, три загрузки с задержкой по одной секунде должны завершиться примерно за одну секунду, а не за три. Результаты должны соответствовать исходным URL, например для "https://example.com/api/users" вернётся "Data from https://example.com/api/users".

    import asyncio async def fetch_data(url: str) -> str: pass async def main(): urls = [ "https://example.com/api/users", "https://example.com/api/products", "https://example.com/api/orders" ] pass if __name__ == "__main__": asyncio.run(main())
