  25. Градиентный спуск для функции одной переменной

    Потренировать производную функции, цикл и базовую формулу градиентного спуска.

    На текущем этапе мы еще как бы не знаем, что такое градиентный спуск, он будет в разделе с Deep Learning. Однако полного осознания не нужно для решения данной задачи. Нужно понимать, что град. спуск. - это про численный поиск минимума функции $f(x)$. Один из популярных методов для этого - градиентный спуск, который предлагается в этой задачке реализовать. Подробнее можно почитать в Блоке 1 DL.

    Рассмотрим функцию:

    $$f(x) = x^2 + \frac{1}{4}x^4$$

    Её минимум можно найти градиентным спуском. Для этого сначала посчитай производную:

    $$f'(x) = 2x + x^3$$

    Напиши функцию gradient_descent(start, learning_rate, steps), которая ищет минимум этой функции.

    • start — начальное значение x;
    • learning_rate — шаг обучения;
    • steps — количество шагов градиентного спуска.

    Начни с x = start, затем steps раз обнови значение по формуле:

    $$x := x - learning\_rate \cdot f'(x)$$
