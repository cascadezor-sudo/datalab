Резервная копия и восстановление

Файл создаётся и читается только на этом устройстве. Он содержит личные учебные данные, не зашифрован и не удостоверяет автора. Храните его в безопасном месте. Максимальный размер — 20 МиБ.

Перед переходом со старой версии закройте остальные вкладки DataLab. Старый JavaScript не соблюдает новый протокол. Изменение legacy-хранилища останавливает новые записи до осознанного разрешения конфликта.

Подготовка сервиса хранения…

Сохранить копию

Включены основная база, черновики, результаты, повторения, настройки, неизвестные поля и архив исходных legacy-ключей с маркерами миграции. Сессии и неаудированные ключи не включаются. Найденные потенциальные секреты блокируют экспорт целиком.

Восстановить файл

Выберите файл для проверки. Ничего не применяется автоматически.

Восстановление заменяет DB и KV целиком: отсутствующие в файле записи будут удалены. Исходный legacy-архив файла сохраняется в самой копии для анализа; он не записывается поверх localStorage и не заменяет локальный архив миграции. Старая отметка anonymous import не запускает повторный импорт.

Непосредственно перед заменой сервис атомарно сохраняет текущее состояние для отмены. Если после предпросмотра другая вкладка записала данные, применение отклоняется: выберите файл повторно.

Отмена и предыдущие состояния

Отмена доступна только пока после импорта не было новых записей. При конфликте сначала сохраните новую копию и сравните версии; автоматическая отмена не уничтожает свежие изменения.

    Изменения от старой вкладки

    Если старый клиент изменил localStorage, сервис блокирует новые записи. Закройте все старые вкладки и сохраните копию текущего состояния. Принять legacy означает явно заменить состояние содержимым legacy-ключей, сохранив предыдущее состояние в архиве. Новые изменения DB могут отличаться от legacy: прочитайте обе версии перед заменой.

    Сначала проверьте изменения. При смене ревизии или legacy-значений потребуется повторная проверка.
