================================================================
          DATALAB — ЛОКАЛЬНАЯ ОФЛАЙН БАЗА ЗНАНИЙ
================================================================

КАК ЗАПУСТИТЬ:
1. Дважды кликните по файлу "Start_DataLab.bat" (или "start.bat").
2. В течение пары секунд откроется браузер по адресу:
   http://localhost:8080/main.html
3. Все темы, формулы, квизы и сохранение прогресса работают на 100% автономно без интернета.

КАК ОСТАНОВИТЬ:
- Просто закройте открывшееся чёрное окно сервера.

ТРЕБОВАНИЯ:
- Установленный Python 3 (или Node.js).
