## Предметы, направления и каталоги

Фактические `categories-config*.json` содержат `group`, `questionPaths`, `roadmapUrl`, `displayName`; присутствуют Python, математика, базы данных, Linux/Git, ML/DL/NLP/CV, MLOps, аналитика, собеседования и другие группы. Это наблюдаемая навигационная классификация. Путь `ai/ml/` сам по себе не доказывает отношения Subject → Course → Module. В каталоге страницы остаются `LegacyPage` с `classification: unclassified`, а исходные категории — `SourceCategory`.

`course-roadmap.json` действительно задаёт учебный маршрут, недельные milestones и tracks. Track href ведёт на HTML roadmap-материал: это не обязательно урок и не автоматически последовательность Lesson. Статические roadmap-страницы, bank-страницы и определения остаются доступны как отдельные материалы. Связь Python/математического упражнения с темой другого урока не создаётся из сходного имени: подтверждена только принадлежность упражнению своей странице и его исходные ключи.

## Противоречия и ограничения

В `registry.issues` сохранены **608 warning, 0 error**:

- Две копии карточек расходятся: 5638/4867 записей, 5628/4857 уникальных ID, 4857 общих уникальных ID с различающимися записями. Сравнение по ID в summary не заменяет lossless-массив: дубли внутри файла остаются отдельными occurrences. Обнаружены 8 неоднозначных scoped flashcard aliases (4 повторяющихся ID в каждой копии).
- `categories-config.json` и `categories-config-live.json` различаются. Каталог не выбирает приоритет автоматически.
- 564 неоднозначных scoped `question-index-id`, 20 повторно используемых roadmap-track ID и одно повторение card-block-topic ID сохраняются как предупреждения о повторном употреблении, а не объявляются 593 потерями данных.
- Два прежних предупреждения EN quiz исправлены в Фазе 3: связи следуют фактическому `registry.json` с EN overlay и fallback из `quiz.js::fetchQuizFile`. Старые quiz ID и существующие источники не менялись. Метаданные `quizResolution` сохраняют выбранный файл и fallback; сетевое поведение этим статическим наблюдением не гарантируется.
- 13 групп вопросов имеют точно одинаковый текст prompt после нормализации пробелов. Это диагностический `duplicate-question-content`, а не доказательство полного совпадения заданий: code/options/answers могут отличаться. Автоматического слияния нет.

9371 глобальный alias неоднозначен с учётом всех namespaces. Это не число конфликтующих учебных тем: сюда входят повторяющиеся DOM anchors, копии источников, категории и другие namespaces. Нельзя выдавать этот счётчик за 9371 ошибок прогресса.

JavaScript разбирается regex только на литеральные `id`/`href`. Динамические значения и сетевые банки интервью не читаются: `interviewQuestionBank`, `mockQuestionBank` и их индексы являются runtime/public projections, а пользовательские feedback, Kanban-задачи, черновики и отметки не являются статическим учебным корпусом. Каталог содержит их конфигурацию/контракт, но не пользовательские записи. HTML inline script templates могут порождать дополнительные маршруты; их полная достижимость не доказана этой инвентаризацией. Внешние URL не обходятся.

Свежесть проверяется SHA-256 **сырых байтов** каждого источника, а не нормализованного текста. `--check` повторно строит каталог и сравнивает с зафиксированным результатом.
